Methodology

Mock dataset. Blended rate held constant per cost center in the $3.20–$8.50 / 1M token band (cc1 $4.20, cc2 $5.50, cc3 $7.20, cc4 $4.80, cc5 $8.10, cc6 $3.80). real_cost_usd = estimated_cost_usd. YTD = May–Sep 2026. Forecast = Oct 2026–Feb 2027 at 4–11% MoM with seasonal noise. FY projection = YTD + forecast. Included tokens = budget ÷ rate × 1.02. Status: Overrun if YTD cost > budget and (variance % < −5 or utilization > 100%); Watch if variance % ≤ 3%; else On track. Tier budgets reconcile to cost-center budget within ±2%. Currency USD only.
